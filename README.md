# Banking Loan Analytics

## Overview
This repository contains a collection of data files, SQL queries, and visual analytics artifacts related to banking loan and credit‑debit transactions. The goal is to provide a **comprehensive analytical toolkit** for exploring loan performance, credit‑debit behavior, and related business insights.

## Data Assets
- **Excel workbooks** (`*.xlsx`) contain raw banking transaction data and loan‑related tables.
- **CSV files** in the `sql/` folder are extracts of the same data used for the SQL examples.
- **PowerBI files (`*.pbix`)** and **Tableau workbooks (`*.twbx`)** provide ready‑made dashboards for:
  - Loan portfolio health
  - Credit‑debit flow analysis
  - Customer segmentation

## SQL Queries
The file `sql/Sql_project_queries.sql` holds a set of queries that demonstrate common analytics tasks such as:
1. **Loan default rate calculation**
2. **Aggregated credit‑debit volumes per month**
3. **Customer‑level loan balance summaries**
4. **Cross‑tab reports for loan approval vs. rejection**

You can run these queries against any SQL‑compatible database after loading the CSV files as tables.

## How to Use the Project
1. **Clone the repository** (or download the ZIP).
2. Open the PowerBI (`*.pbix`) or Tableau (`*.twbx`) files with their respective tools to explore the interactive dashboards.
3. Load the CSV files into your favourite SQL engine (e.g., SQLite, PostgreSQL) and execute the queries in `Sql_project_queries.sql`.
4. Use the Excel files for deeper ad‑hoc analysis in Microsoft Excel or Google Sheets.

## Getting Started with the Data (SQLite example)
```bash
# Create a SQLite database and import CSVs (requires csvsql from csvkit)
csvsql --db sqlite:///banking.db --tables bank_data --insert sql/Bank\ Data\ Analystics.csv
csvsql --db sqlite:///banking.db --tables debit_credit --insert sql/"Debit and Credit bankingg_data.csv"
# Run a query
sqlite3 banking.db "SELECT year, SUM(loan_amount) AS total_loan FROM bank_data GROUP BY year;"
```
